# گزارش بررسی و وضعیت تأیید

وضعیت: سورس عمومی و APK آزمایشی موجود است؛ نسخه پایدار منتشر نشده است.

## مبنای سورس

ZIP نهایی مالک مبنا بود؛ APK و تاریخچه Git اولیه در آن نبود. بنابراین نسبت باینری قدیمی مک با این سورس تأیید نشده است. فایل‌های Dock، ویرایشگر، Launchpad، تلکس، تاریخ شمسی و ساعت در کد حضور دارند و به صفحه اصلی متصل‌اند.

## ساخت موفق

[ساخت Release](https://github.com/xxamr/CleanYourTV-Persian-MacDock/actions/runs/39852363967) با Java 17، API 34، ابزار ساخت 34.0.0، آزمون JVM و lint موفق شد. تلاش محلی به‌دلیل دسترسی‌نداشتن به سرور Gradle متوقف شده بود؛ موفقیت CI این محدودیت ساخت را پوشش داد، نه تست دستگاه واقعی را.

[ساخت APK آزمایشی](https://github.com/xxamr/CleanYourTV-Persian-MacDock/actions/runs/39853484103) از commit `27e5fec2073ea621ff6f32db7760c0d79ea2f207` موفق شد: آزمون `testPreviewUnitTest`، بررسی `lintPreview`، ساخت `assemblePreview`، کنترل شناسه برنامه و تأیید امضای APK. فایل با شناسه `com.gathin.tvhome.preview` و امضای موقت Debug منتشر شد. هش و اثرانگشت در فایل‌های همراه انتشار موجود است.

## اصلاحات انتشار

امضای Debug از نوع Release برداشته شد؛ Preview کانال جداگانه دارد. دریافت RSS تغییرمسیر را دنبال نمی‌کند و DTD رد می‌شود. فایل‌های پشتیبان محلی اضافی کنار گذاشته و مستندات و خطای دکمه‌های جدید در چیدمان عبری اصلاح شدند. بررسی برابری شناسه نماهای عبری و لینک‌های Markdown پس از اصلاح موفق بود.

## آزمون‌های Python به‌ارث‌رسیده

اجرای اولیه: ۴۲۹ آزمون، ۱۳ شکست، ۵ خطا و ۳ مورد ردشده از اجرا. بیشتر موارد به README و گردش‌کارها و سقف حجم پروژه اصلی متکی‌اند و هنوز کامل با این نسخه تطبیق داده نشده‌اند. این مجموعه، موفق اعلام نشده است. خطای واقعی چیدمان عبری در همین بررسی پیدا و اصلاح شد.

## چه چیزهایی هنوز تأیید نشده‌اند؟

نصب APK آزمایشی، آپدیت، بازیابی Home، عملکرد همه ریموت‌ها، رفتار زبان ساعت، دسترسی زنده همه منابع و مصرف منابع روی TV واقعی تأیید نشده‌اند. عکس ارسالی مالک شواهد ظاهر نسخه سفارشی است، نه اثبات نصب همین APK.

بررسی عملی فایل‌ها برای اطلاعات حساس انجام شده، اما این کار ممیزی امنیتی جامع یا تضمین نبود آسیب‌پذیری نیست. پیش از نسخه پایدار، کلید ثابت و آزمون‌های واقعی نصب و آپدیت و بازگشت لازم‌اند.
