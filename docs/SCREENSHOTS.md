# تصاویر قبل و بعد

تصاویر README را مالک برای همین مقایسه ارائه کرده است. تصویر مرجع `screenshots/stock-home-reference.webp` از Home پیش‌فرض روی تلویزیونی متفاوت است؛ نام فایل اولیه، نسخه اندروید یا دستگاه را به‌طور مستقل اثبات نمی‌کند. تصویر `screenshots/custom-home-owner.jpg` عکس واقعی Home سفارشی با یک Dock، تاریخ شمسی و تلکس است. این عکس، commit یا گواهی امضای فایل نصب‌شده را مشخص نمی‌کند.

تصاویر بدون بازسازی یا تولید مصنوعی منتشر شده‌اند. عکس قدیمی دارای دو Dock و عکس‌های تنظیمات با شناسه دستگاه منتشر نشده‌اند. مجوز گسترده‌تری برای استفاده مجدد از تصاویر ثالث ادعا نمی‌شود.

## گرفتن تصویر جدید

روی کامپیوتری که از قبل با ADB به باکس مجاز شده، Home اصلی را باز کنید و در مک یا لینوکس اجرا کنید:

```sh
adb exec-out screencap -p > home-before.png
```

سپس Home سفارشی را باز کنید، بدون حذف یا غیرفعال‌کردن برنامه‌های دیگر:

```sh
adb exec-out screencap -p > home-after.png
```

در ویندوز این انتقال باینری را در Command Prompt اجرا کنید؛ PowerShell قدیمی ممکن است خروجی PNG را خراب کند. اگر ADB در PATH نیست، مسیر `adb.exe` را به کار ببرید. دستورها فرض می‌کنند فقط یک دستگاه مجاز متصل است.

پیش از انتشار، نام شبکه، حساب، اعلان، خبر خصوصی و شناسه دستگاه را بررسی کنید. هر برش یا پوشاندن اطلاعات باید اعلام شود. عکس نسخه مک را تست نصب APK آزمایشی CI معرفی نکنید. برای تصویرگرفتن لازم نیست Home اصلی را غیرفعال کنید.
