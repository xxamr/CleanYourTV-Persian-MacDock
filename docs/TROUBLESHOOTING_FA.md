# رفع مشکلات متداول

## ADB وصل نمی‌شود / unauthorized

- تلویزیون روشن و در همان شبکه قابل دسترس باشد؛ `adb connect <TV_IP>:5555`.
- درخواست Debugging روی TV را تأیید کنید.
- در `adb devices -l` وضعیت باید `device` باشد، نه `unauthorized` یا `offline`.
- برخی TVها پس از ری‌استارت Wireless debugging را غیرفعال می‌کنند.

## `set-home-activity` می‌گوید Success، اما Google TV باز می‌شود

این رفتار روی بعضی Firmwareهای Xiaomi/Google TV مستند شده است. صفحه انتخاب Home را در Settings بررسی کنید و با **دکمه فیزیکی Home** تست کنید؛ صرفاً به جواب Shell تکیه نکنید. **لانچر سیستمی را حذف نکنید.** پیش از هر غیرفعال‌سازی، راه بازگشت و دسترسی ADB را تأیید کنید.

## بازیابی لانچر کارخانه

از نام بسته و component واقعی که پیش از تغییر Home ثبت کردید استفاده کنید؛ نام Google TV معمولاً `com.google.android.apps.tv.launcherx` است و با Android TV فرق دارد:

```bash
adb shell pm enable --user 0 <STOCK_HOME_PACKAGE>
adb shell cmd package set-home-activity <RECORDED_STOCK_HOME_COMPONENT>
adb shell input keyevent KEYCODE_HOME
```

اگر اسم بسته کارخانه متفاوت است، از لیست `cmd package query-activities` همان دستگاه استفاده کنید.

## صفحه اصلی سیاه، Crash یا کندشدن

```bash
adb shell am start -n com.gathin.tvhome/.MainActivity
adb shell dumpsys meminfo com.gathin.tvhome
adb logcat -d -s AndroidRuntime:E
```

قبل از ثبت Issue، اطلاعات خصوصی را از Log پاک کنید. Build آخرین نسخه را با `./gradlew assembleDebug` بازتولید کنید. اگر Home بالا نمی‌آید ابتدا لانچر کارخانه را بازیابی کنید.

## تیترهای خبری نمایش داده نمی‌شوند

- تلکس از منوی بالا فعال باشد و دست‌کم یک **منبع** و یک **موضوع** انتخاب شده باشد.
- اینترنت روی خود TV قابل استفاده باشد، نه فقط روی کامپیوتر.
- RSSهای بعضی سایت‌ها ممکن است مسدود، کند یا تغییر یافته باشند؛ آخرین تیترهای ذخیره‌شده می‌توانند نمایش داده شوند.
- ساعت و منطقه زمانی TV درست باشند؛ اتصال HTTPS به ساعت صحیح نیاز دارد.
- برخی دسته‌ها از فیلتر کلیدواژه استفاده می‌کنند و ممکن است اخبار مرتبط را از دست بدهند.

## تاریخ اشتباه است

ابتدا تاریخ/منطقه زمانی خود Android TV را اصلاح کنید. تبدیل شمسی از تاریخ تقویم دستگاه انجام می‌شود. تغییر منطقه زمانی دستگاه با تنظیمات سایت خبری متفاوت است.

## YouTube/Browser یا سایر اپ‌ها باز نمی‌شوند

باید خود برنامه نصب و فعال باشد؛ Dock صرفاً Shortcut است. برخی APKهای موبایل از D-pad پشتیبانی کامل ندارند.

## فایل‌های راهنمای اصلی

برای خطرات وابسته به Firmware، مستندات پروژه مادر در `docs/TROUBLESHOOTING.md` را هم بخوانید: https://github.com/Gathin23/cleanyourtv/blob/main/docs/TROUBLESHOOTING.md

## ابزار ADB پیدا نمی‌شود

در مک داخل پوشه ابزار از `./adb` و در PowerShell از `.\adb.exe` استفاده کنید. فایل را از ZIP بیرون بیاورید. برای این روش نیازی به تغییر PATH نیست. `No such file` یا `not recognized` معمولاً به مسیر یا پیشوند مربوط است.

## اتصال رد می‌شود یا زمان تمام می‌شود

IP واقعی را از باکس دوباره بخوانید؛ پس از راه‌اندازی مجدد ممکن است عوض شده باشد. روشن‌بودن debugging و دسترسی دو دستگاه در شبکه را بررسی کنید. شبکه مهمان، جداسازی دستگاه‌ها، VPN یا فایروال می‌توانند مسیر را محدود کنند. وجود گزینه USB debugging به‌تنهایی اثبات نمی‌کند Firmware روی پورت ۵۵۵۵ گوش می‌دهد. اگر دستگاه از جفت‌سازی کدی استفاده می‌کند، پورت‌های همان صفحه را به کار ببرید.

## چند دستگاه متصل‌اند

خطای `more than one device/emulator` با انتخاب هدف درست حل می‌شود؛ شناسه خروجی `devices -l` را با گزینه `-s` در هر دستور محلی مشخص کنید. شناسه را در گزارش عمومی نفرستید.

## خطاهای نصب

| پیام | اقدام |
|---|---|
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | امضا با نسخه موجود فرق دارد؛ قبل از حذف نسخه آزمایشی به Home قبلی برگردید و تنظیمات لازم را ثبت کنید. |
| `INSTALL_FAILED_OLDER_SDK` | اندروید دستگاه پایین‌تر از حداقل برنامه است؛ حداقل API را برای اجبار نصب پایین نیاورید. |
| `INSTALL_FAILED_INSUFFICIENT_STORAGE` | فضای آزاد باکس را بررسی کنید؛ داده برنامه‌های دیگر را بدون بررسی پاک نکنید. |
| `INSTALL_FAILED_VERSION_DOWNGRADE` | فایل قدیمی‌تر روی نسخه جدید نصب می‌شود؛ روش کاهش نسخه را بدون بررسی داده و امضا اجبار نکنید. |
| `no devices/emulators found` | ابتدا اتصال و وضعیت `device` را برقرار کنید. |

## Preview نصب شده اما دستور اجرای نسخه اصلی خطا می‌دهد

شناسه فایل آماده جداست. مؤلفه درست آن `com.gathin.tvhome.preview/com.gathin.tvhome.MainActivity` است؛ دستور `com.gathin.tvhome/.MainActivity` نسخه دیگری را هدف می‌گیرد. نام برنامه در فهرست تلویزیون **CleanYourTV Preview** است.
