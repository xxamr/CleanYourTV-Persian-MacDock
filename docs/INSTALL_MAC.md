# نصب APK آماده با مک

این روش برای نصب فایل آماده است؛ **Java، Android Studio، Gradle و ساخت سورس لازم نیست**. نام فایل `CleanYourTV-experimental.apk` و نام برنامه نصب‌شده `CleanYourTV Preview` است. نسخه آزمایشی امضای موقت دارد؛ [محدودیت‌ها](EXPERIMENTAL_APK.md) را بخوانید.

## ۱. دانلود دو فایل مورد نیاز

- [APK آزمایشی پروژه](https://github.com/xxamr/CleanYourTV-Persian-MacDock/releases/download/experimental-27e5fec-1-1/CleanYourTV-experimental.apk).
- از [صفحه رسمی Android Platform Tools](https://developer.android.com/tools/releases/platform-tools)، گزینه `Download SDK Platform-Tools for Mac` را انتخاب کنید، شرایط را بخوانید و در صورت پذیرش دانلود کنید.

ZIP ابزار را با دوبار کلیک باز کنید. پوشه `platform-tools` را داخل Downloads قرار دهید؛ فایل APK را هم داخل همین پوشه کپی کنید. نام فایل را تغییر ندهید. فایل سورس ZIP جای APK نیست و نباید آن را روی باکس نصب کنید.

## ۲. بازکردن ترمینال و بررسی ابزار

از Spotlight یا پوشه Utilities برنامه Terminal را باز کنید:

```sh
cd "$HOME/Downloads/platform-tools"
./adb version
ls -l CleanYourTV-experimental.apk
```

اگر پوشه را جای دیگری گذاشته‌اید، مسیر واقعی آن را وارد کنید. نمایش نسخه ADB و مشخصات فایل یعنی ابزار و APK در مسیر درست‌اند. پیشوند `./` لازم است؛ این راهنما نیازی به تغییر PATH ندارد.

### مک‌های قدیمی، از جمله Catalina

Homebrew لازم نیست. فقط از ابزار رسمی و نسخه سازگار با سیستم‌عامل خودتان استفاده کنید. اگر ابزار فعلی گوگل روی macOS قدیمی اجرا نشد، نصب این نسخه ابزار روی آن سیستم تأیید نشده است؛ از کامپیوتر با سیستم‌عامل پشتیبانی‌شده استفاده کنید یا نسخه سازگار رسمی را بررسی کنید. اگر macOS فایل را مسدود کرد، منشأ دانلود را بررسی و از مسیر تأیید معمول سیستم‌عامل اقدام کنید؛ محافظت سیستم را خاموش نکنید.

## آماده‌کردن باکس

۱. باکس و کامپیوتر را به شبکه قابل دسترس وصل کنید؛ شبکه مهمان ممکن است ارتباط دستگاه‌ها را مسدود کند.
۲. در تنظیمات باکس، بخش «درباره دستگاه» یا `About` را باز و روی شماره ساخت یا `Build` چند بار، معمولاً هفت بار، بزنید تا گزینه‌های توسعه‌دهنده فعال شود.
۳. در `Developer options`، اشکال‌زدایی USB یا شبکه را در صورت پشتیبانی دستگاه روشن کنید. در Mi Box ممکن است نام گزینه USB debugging باشد؛ دسترسی روی شبکه به Firmware بستگی دارد.
۴. IP دستگاه را از تنظیمات شبکه یا بخش `Status` پیدا کنید. این IP را عمومی منتشر نکنید.
۵. صفحه تلویزیون و ریموت در دسترس باشد تا درخواست اعتماد به کامپیوتر را تأیید کنید. فقط روی کامپیوتر مورد اعتماد خودتان گزینه اعتماد همیشگی را انتخاب کنید.

اگر دستگاه فقط گزینه جفت‌سازی Wireless debugging با کد دارد، از IP و پورت‌هایی که همان صفحه نشان می‌دهد و روش جفت‌سازی انتهای این راهنما استفاده کنید؛ پورت ۵۵۵۵ را برای آن حدس نزنید. همه باکس‌ها این قابلیت را ندارند.

## ۳. اتصال و تأیید روی تلویزیون

دستور زیر IP را از شما می‌پرسد؛ فقط IP باکس خودتان را وارد کنید:

```sh
printf 'IP دستگاه را وارد کنید: '
read -r TV_IP
./adb connect "${TV_IP}:5555"
./adb devices -l
```

روی تلویزیون درخواست USB debugging را تأیید کنید و دوباره دستور آخر را اجرا کنید. وضعیت باید `device` باشد؛ `unauthorized` یعنی تأیید هنوز انجام نشده است. `offline` یا نبود دستگاه را پیش از نصب برطرف کنید. اگر چند دستگاه متصل‌اند، نصب را متوقف و دستگاه درست را مشخص کنید؛ می‌توانید در هر دستور از `./adb -s "${TV_IP}:5555" ...` استفاده کنید.

## ۴. ثبت Home قبلی

```sh
./adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
```

خروجی شامل نام بسته و Activity است. آن را در یک یادداشت محلی ذخیره کنید؛ این نام، مسیر بازگشت شماست. بسته را از روی دستگاه دیگری حدس نزنید.

## ۵. نصب و اجرای APK آماده

```sh
./adb install -r ./CleanYourTV-experimental.apk
./adb shell am start -n com.gathin.tvhome.preview/com.gathin.tvhome.MainActivity
```

بعد از نمایش `Success` برنامه باز می‌شود. اگر خودکار باز نشد، از فهرست برنامه‌های باکس **CleanYourTV Preview** را انتخاب کنید. این نسخه کنار لانچر قبلی نصب می‌شود و تنظیمات آن را منتقل نمی‌کند.

## ۶. آزمون اولیه و انتخاب Home

پیش از تغییر Home، حرکت ریموت، بازشدن برنامه‌ها، Back، تنظیم برنامه‌های دلخواه و تلکس را امتحان کنید. سپس در تنظیمات دستگاه، برنامه‌های پیش‌فرض و Home را پیدا و Preview را انتخاب کنید. در دستگاه پشتیبانی‌شده:

```sh
./adb shell cmd package set-home-activity com.gathin.tvhome.preview/com.gathin.tvhome.MainActivity
```

Home فیزیکی ریموت را بزنید. اگر لانچر قبلی باز شد، دستور موفق ظاهری کافی نیست؛ Firmware ممکن است انتخاب Home دیگر را محدود کرده باشد. برنامه اصلی یا setup wizard را برای رفع این مسئله غیرفعال نکنید.

## ۷. بازگشت به صفحه اصلی قبلی

از تنظیمات دستگاه Home قبلی را انتخاب کنید. اگر ADB لازم شد، این قطعه مؤلفه‌ای را که در مرحله ۴ ثبت کرده‌اید می‌پرسد:

```sh
printf 'مؤلفه Home قبلی را وارد کنید: '
read -r STOCK_HOME_COMPONENT
./adb shell cmd package set-home-activity "$STOCK_HOME_COMPONENT"
./adb shell input keyevent KEYCODE_HOME
```

برای حذف Preview ابتدا به Home قبلی برگردید و سپس در تنظیمات برنامه‌های باکس آن را حذف کنید. تنظیمات Preview با حذف آن پاک می‌شود. داده‌های لانچر اصلی را پاک نکنید.

## ۸. پایان کار

```sh
./adb disconnect
```

قطع اتصال به‌تنهایی اشکال‌زدایی دستگاه را خاموش نمی‌کند. در تلویزیون debugging را خاموش، مجوزهای اعتماد را لغو و دستگاه را راه‌اندازی مجدد کنید.

## روش جفت‌سازی در دستگاه‌های دارای Wireless debugging

IP، پورت جفت‌سازی و کد را از صفحه جفت‌سازی دستگاه بگیرید:

```sh
./adb pair <PAIRING_IP>:<PAIRING_PORT>
./adb connect <DEVICE_IP>:<CONNECT_PORT>
./adb devices -l
```

جای‌نگهدارها را قبل از اجرا جایگزین کنید. پورت اتصال با پورت جفت‌سازی می‌تواند متفاوت باشد. این روش در همه Android TVها، به‌ویژه Firmwareهای قدیمی، وجود ندارد.
