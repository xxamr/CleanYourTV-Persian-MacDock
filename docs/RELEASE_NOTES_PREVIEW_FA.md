# APK آزمایشی آماده نصب

**نسخه پایدار نیست.** این فایل با نام **CleanYourTV Preview** و شناسه جداگانه `com.gathin.tvhome.preview` کنار لانچر قبلی نصب می‌شود.

## نصب با مک یا ویندوز

- [راهنمای قدم‌به‌قدم مک](https://github.com/xxamr/CleanYourTV-Persian-MacDock/blob/main/docs/INSTALL_MAC.md)
- [راهنمای قدم‌به‌قدم ویندوز](https://github.com/xxamr/CleanYourTV-Persian-MacDock/blob/main/docs/INSTALL_WINDOWS.md)
- [نصب و محدودیت‌های APK آماده](https://github.com/xxamr/CleanYourTV-Persian-MacDock/blob/main/docs/EXPERIMENTAL_APK.md)
- [کار با ریموت، ساعت و تلکس](https://github.com/xxamr/CleanYourTV-Persian-MacDock/blob/main/docs/USER_GUIDE_FA.md)

از فایل‌های پایین صفحه، `CleanYourTV-experimental.apk` را دانلود کنید. ZIP سورس فایل نصب نیست. Java و Android Studio برای نصب APK آماده لازم نیستند. ابتدا برنامه را بدون تغییر Home باز کنید؛ لانچر کارخانه را حذف یا غیرفعال نکنید.

## امضا و نتیجه بررسی

امضا از نوع Debug و موقت CI است؛ ممکن است فایل اجرای بعدی با کلید دیگری ساخته شود و آپدیت مستقیم پذیرفته نشود. حذف Preview تنظیمات خودش را پاک می‌کند. نصب، آپدیت و بازیابی روی دستگاه واقعی تأیید نشده‌اند.

آزمون‌های JVM، lint، ساخت، کنترل شناسه و بررسی امضای APK موفق بوده‌اند. سورس فایل نصب، commit `27e5fec2073ea621ff6f32db7760c0d79ea2f207` است. این ویرایش فقط راهنما را فارسی می‌کند؛ فایل APK عوض نشده است. `SHA256SUMS.txt` برای بررسی هش APK و `BUILD-INFO.txt` برای مشخصات فنی ساخت و گواهی همراه‌اند.

این نسخه غیررسمی بر پایه Gathin23/cleanyourtv است. مجوز MIT و مجوز فونت OFL حفظ شده‌اند. نسخه پایدار نیاز به کلید ثابت و تست واقعی دارد.
